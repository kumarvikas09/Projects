# Project Memory

## Project Type
Tartan & Thistle Web Application

## Design Source

## Framework
Bootstrap 5

## Fonts
Primary: Cormorant Garamond ("Cormorant Garamond", serif) -> `--ff-cormorant`
Secondary: None
Typography variables available: Yes (--fs-120 down to --fs-16, --ff-cormorant)

## Icons
- Custom SVG Icons in `assets/Icons/` (Shopping Bag, Search, Dog, Heart, Star, Priority Booking, Birthday, Calm, Sleep, Upgrade, etc.)

## Imagery
- High-res photography and graphics in `assets/images/` (`CC - Clan Reid.webp`, `nav-logo.webp`, `footer-logo.webp`, Bath Photo, Bear, Connie, Moxie, Smith and Burton products, etc. in `.webp` format)

## Libraries
- jQuery (jquery.min.js)
- Bootstrap 5 (bootstrap.bundle.min.js / bootstrap.min.css)

## Global Components
- Primary Button (`.primary_btn`, `.primary_btn.white`)
- Section Heading (`.sec_hdng`)
- Spacing Utilities (`.pt_100`, `.pb_100`, `.pt_50`, `.pb_50`, `.mt_100`, `.mb_100`, `.mt_50`, `.mb_50`)
- Site Header (`.site_header`, `.sticky`)
- Hamburger Menu (`.hemburger`)
- What Makes Us Different (`.difference_section`)
- Site Footer (`.site_footer`)

## Notes
- Do NOT start live server or dev server commands; the user runs the server manually.
- Use `assets/images/` and `assets/Icons/` directly for all asset references.
- Standard container width is set to 1440px across all sections including the header (`.container` max-width: 1440px).
- Global variables located in `assets/css/main-style.css`:
  - Colors: `--clr-222d3c`, `--clr-gold`, `--clr-gold-light`, `--clr-dark-bg`, `--clr-white`, `--clr-black`
  - Font sizes: `--fs-120`, `--fs-80`, `--fs-64`, `--fs-52`, `--fs-40`, `--fs-34`, `--fs-30`, `--fs-28`, `--fs-25`, `--fs-24`, `--fs-22`, `--fs-20`, `--fs-18`, `--fs-16`
  - Spacing: `--spc-100`, `--spc-50`
  - Header height variable: `--headerHeight`
